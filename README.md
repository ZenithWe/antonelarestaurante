# Antonella Restaurante — site premium

Site estático responsivo com visual bordô/vinho, creme e detalhes champagne.

## Arquivos
- `index.html` — estrutura
- `styles.css` — visual responsivo
- `script.js` — menu, animações e instalação PWA
- `manifest.json` + `sw.js` — instalação como aplicativo
